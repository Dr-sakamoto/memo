# 🍇 MEMO — 自分だけのCNS（Closed Network Service）

日記・反省・分析・人生計画・思考ログのための、**自分ひとりのSNS**。
Xや755のような使用感で自分に向けてポストし、AIが「唯一の他者の目」として応答する。
1週間育てると**発芽**し、過去の自分のポストが電光掲示板のように流れてくる。

コンセプトは**ブドウの木**。刻んだ記録は葉になり、過去の自分を引用（接ぎ木）するたびに房が実る。

## 特徴

- **完全ローカル・依存ゼロ** — ビルド不要の素のHTML/CSS/JS。全データはブラウザのlocalStorageに保存され、どこにも送信されない（AI利用時のみ、自分のブラウザからAnthropic APIへ直接送信）。「閉じたネットワーク」そのもの
- **タイムライン** — 日記/反省/分析/計画/思考の5種のポスト。気分（-2〜+2）とハッシュタグを添えられる
- **再芽（セルフRT）と接ぎ木（セルフ引用）** — 過去の自分のポストを再掲・引用する。引用されたポストは**質量（Mass）**が増え、電光掲示板に浮上しやすくなる
- **電光掲示板** — 7日間活動して発芽すると解禁。過去のポストが質量×節目重力（1週間前・1ヶ月前・1年前・5年前・10年前の周辺は強く引かれる）の重み付き抽選で流れてくる。クリックするとその場で接ぎ木できる
- **時間軸ビュー** — 1週間前・1ヶ月前・3ヶ月前・1年前・5年前・10年前の「その頃の自分」を一覧
- **ブドウの木** — 活動日数で成長：種 → 発芽(7日) → 蔓(21日) → 葉(60日) → 花(180日) → 実(365日)。SVGで描画され、ポストが葉に、引用が房になる
- **AI＝唯一の他者** — Anthropic APIキーを設定すると：
  - 期間分析（1週間〜10年）：感情の傾向、気づいていない視点、次の一手を手紙形式で
  - ポストへの返信（「AIの目」ボタン、または自動返信モード）
  - キーが無くてもローカル統計分析（気分の推移・頻出タグなど）は動作
- **エクスポート/インポート** — JSON一括バックアップ

## 使い方

ES Modulesを使っているため、ローカルHTTPサーバーで開きます：

```sh
cd memo
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

または `npx serve` など任意の静的サーバーでOK。

### AI連携の設定

1. [Anthropic Console](https://console.anthropic.com/) でAPIキーを取得
2. アプリの「設定」タブでキーを貼り付けて保存
3. キーはlocalStorageにのみ保存され、ブラウザから `api.anthropic.com` へ直接送信されます（CORS対応の `anthropic-dangerous-direct-browser-access` ヘッダーを使用）。共有PCでは使用しないでください

## アルゴリズム（過去設計「ワタアメ宇宙」からの移植）

| 概念 | 本アプリでの実装 |
|---|---|
| 質量 (Mass) | `1 + 引用×2.0 + 再掲×1.2 + 文章量補正 + AI返信0.5`。ポスト自身の存在強度 |
| 重量 (Weight) | `Mass × 節目重力`。電光掲示板の抽選確率を決める方向性のある力 |
| 節目重力 | 投稿からの経過日数が 7日/30日/90日/1年/5年/10年 の節目に近いほど強く引かれる（1年=×5.0、10年=×8.0 など） |
| 親子構造 / Co-Growth | 引用（接ぎ木）による親子関係。引用された親だけが質量を得る＝波及は直接の親のみ |
| ワタ（クラスタ） | 引用でつながった記録のまとまり＝ブドウの「房」として可視化 |

```
js/vine.js      — ブドウの木の成長モデルとSVG描画
js/ai.js        — Claude API連携＋ローカルフォールバック分析
js/app.js       — UIコントローラ
```
